# TripAdvisor Clone Website

A fully responsive front-end clone of the TripAdvisor website built using HTML5 and CSS3. This project focuses on responsive web design principles and modern CSS layout techniques such as Flexbox, positioning, and media queries.

---

## 🚀 Project Overview

This project is a static clone of the TripAdvisor homepage created to practice and improve front-end development skills. The website layout is designed to closely resemble the original TripAdvisor UI while maintaining responsiveness across different screen sizes and devices.

---

## ✨ Features

- Responsive navigation bar
- Responsive image cards and sections
- Search bar UI
- Sticky header with scroll effects
- Hover effects
- Responsive layouts for:
  - Desktop
  - Tablet
  - Mobile devices
- Footer section with links
- Modern UI design using Flexbox and CSS positioning

---

- HTML5

## 📱 Responsive Design

Media queries were used to make the website responsive for different screen sizes. The layout automatically adjusts for:

- Large screens
- Tablets
- Mobile devices

Responsive techniques used:
- Flex wrapping
- Percentage widths
- Relative positioning
- Responsive typography
- Adaptive image scaling

---

## 🎯 Key CSS Concepts Practiced

### Flexbox
Used for:
- Navigation bar alignment
- Card layouts
- Footer links
- Responsive sections

### CSS Positioning
Used for:
- Overlay text on images
- Button placements
- Sticky header effects

### Media Queries
Used to:
- Adjust layouts for smaller screens
- Stack elements vertically
- Resize fonts and images
- Improve mobile responsiveness
